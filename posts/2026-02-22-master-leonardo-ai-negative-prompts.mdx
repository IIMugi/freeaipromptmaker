A negative prompt tells Leonardo what you do not want in the image. Leonardo's help center calls it "a great first defence" against unwanted details such as extra limbs or digits. The catch in 2026: many of the newer models on Leonardo have no negative prompt at all. This page shows where the field is, which models have it, and lists you can paste in.

## Where to find the negative prompt field

In the web app's image creation page:

1. Pick a model that supports negative prompts (see the table below).
2. Open **Advanced Settings** in the side bar.
3. Toggle on **Negative Prompt**. A second text field appears under the main prompt.

Leonardo's own prompting guide shows these steps with Ideogram 3.0. If you do not see the toggle, the selected model does not take a negative prompt; switch model or use the tips in [models without a negative prompt](#models-without-a-negative-prompt).

In the API, the field is `negative_prompt` inside `parameters`:

```json
{
  "model": "phoenix-v1.0",
  "parameters": {
    "prompt": "portrait of a lighthouse keeper, weathered face, overcast coastal light",
    "negative_prompt": "blurry, extra fingers, text, watermark"
  },
  "public": false
}
```

## Copy-paste negative prompt lists

Write a negative prompt as a list of things, not as a sentence. Do not write "no" or "without" in the negative field: the field already means "not this".

### General cleanup

```text
blurry, low quality, lowres, jpeg artifacts, out of focus, overexposed, underexposed, watermark, signature, text, logo
```

### People and portraits

```text
extra fingers, missing fingers, fused fingers, extra hands, extra arms, extra legs, deformed hands, distorted face, asymmetrical eyes, cross-eyed, bad anatomy, long neck
```

### Photorealistic images

```text
cartoon, anime, illustration, painting, drawing, 3d render, cgi, plastic skin, airbrushed, oversaturated
```

### Anime and illustration

```text
photo, photorealistic, 3d, realistic skin texture, blurry lines, messy lineart, extra limbs, bad hands, text, watermark
```

### Product shots and graphic design

```text
text, letters, watermark, logo, cluttered background, harsh shadows, reflections, dust, scratches, cropped product
```

### Landscapes and architecture

```text
people, cars, power lines, text, watermark, tilted horizon, distorted buildings, blurry, overprocessed, hdr halos
```

### Safe-for-work filter

The help center names nudity as a typical thing to keep out with a negative prompt:

```text
nudity, nsfw, gore, blood, revealing clothing
```

Combine lists as needed, but keep it short. Start with the 3–6 terms for the problem you actually see, then add more only if it stays.

## Models without a negative prompt

On Lucid, FLUX, GPT Image, Nano Banana and the other models without the field, put the fix in the main prompt instead. Leonardo's prompting guide also recommends trying a positive prompt first, because negative prompts are soft constraints.

| Instead of a negative... | Write in the prompt |
| --- | --- |
| `text, watermark` | "clean image with no text or lettering" |
| `people` | "an empty street at dawn" |
| `blurry` | "sharp focus, crisp detail" |
| `cluttered background` | "on a plain white seamless background" |
| `cartoon` | "a realistic photograph, natural skin texture" |

Describe the result you want ("an empty beach") rather than "a beach, no people": the second version still puts "people" in the prompt.

## When something still shows up

Leonardo's help center gives this order:

1. Add the unwanted element to the negative prompt.
2. If it still appears, change the **model**, the **aspect ratio**, or the **style** preset.
3. If that does not work, remove it by hand in **Canvas**: mask the area and regenerate it with a new prompt.

Two notes from the official docs:

- Leonardo says PhotoReal's settings were optimized so that it does not need a negative prompt.
- Negative prompts lower the weight of unwanted terms rather than blocking them, so they make an element less likely, not impossible.
